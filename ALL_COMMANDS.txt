1. 👑 ADMIN COMMANDS (TYPE THESE IN WHATSAPP CHAT)
--------------------------------------------------------------------------------
You (the Owner) can send these commands directly inside any WhatsApp chat:

• #stats
  -> Shows total active leads, business inquiries, and bot status.

• #leads
  -> Same as #stats, gives real-time CRM lead count.

• #pause
  -> Pauses the AI bot for that specific customer chat so you can talk personally.

• #resume
  -> Re-activates the AI bot for that customer chat.

• #help
  -> Sends the full admin cheat-sheet directly in WhatsApp.

• #commands
  -> Same as #help.

• REVISE CLIENT QUOTE (TYPE IN YOUR SELF-CHAT):
  -> "Quote Deepa 13000 instead of 15000"
  -> "Deepa la 13000 quote kar"
  -> "Revise Deepa's price to 13k"
  * Action: The bot reads Deepa's exact chat history, generates a revised scope breakdown & proposed WhatsApp message, and asks you if you want to dispatch it directly to Deepa on WhatsApp (Reply "Send to Deepa" or "Yes" to send)!

• LIVE TRAIN / RE-CONFIGURE BOT (TYPE IN YOUR SELF-CHAT):
  -> "Update basic website price to 5k"
  -> "We now offer Flutter mobile apps starting at 25000"
  -> "Always offer 10% discount for college students"

3. 💻 TERMINAL / PC RUN COMMANDS (LOCAL EXECUTION)
--------------------------------------------------------------------------------
Open terminal / command prompt in "E:\Whatsapp Chatbot":

• START BOT (Auto-Restart Loop):
  run.bat

• START BOT VIA NODE:
  npm start
  (or: node index.js)

• INSTALL DEPENDENCIES:
  npm install

• RESET / CLEAR WHATSAPP SESSION (TO SCAN NEW QR):
  rmdir /s /q auth_session

• VIEW CAPTURED LEADS:
  type leads.json

• VIEW PERSISTENT CHAT HISTORY:
  type data\chat_history.json
